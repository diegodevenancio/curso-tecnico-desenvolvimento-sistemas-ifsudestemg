# 💻 Curso Técnico em Desenvolvimento de Sistemas

Repositório destinado à organização e documentação dos estudos realizados durante o **Curso Técnico em Desenvolvimento de Sistemas**, oferecido pelo **Instituto Federal do Sudeste de Minas Gerais (IF Sudeste MG)**, na modalidade **Educação a Distância (EaD)**.

Aqui estão organizados os materiais de estudo, exercícios, atividades, projetos, códigos, resumos e anotações desenvolvidos ao longo da formação.

## 🎓 Sobre o curso

* **Curso:** Técnico em Desenvolvimento de Sistemas
* **Instituição:** Instituto Federal do Sudeste de Minas Gerais (IF Sudeste MG)
* **Modalidade:** Educação a Distância (EaD)
* **Situação:** Em andamento
* **Início:** 2026

## 📚 Organização do repositório

O conteúdo está organizado por período, disciplina e categoria de material, facilitando a localização e a manutenção dos arquivos durante o curso.

```text
curso-tecnico-desenvolvimento-sistemas/
├── 1° Período/
│   ├── Disciplina-1/
│   │   ├── atividades/
│   │   ├── exercicios/
│   │   ├── projetos/
│   │   ├── codigos/
│   │   └── resumos/
│   ├── Disciplina-2/
│   └── ...
├── 2° Período/
│   └── ...
├── 3° Período/
│   └── ...
└── .gitignore
```

Cada disciplina possui pastas próprias para organizar os materiais, as atividades práticas e os conteúdos produzidos durante os estudos.

As pastas de avaliações são mantidas apenas no ambiente local e não são enviadas ao GitHub.

A estrutura será preenchida e atualizada progressivamente conforme o avanço da formação e a inclusão de novos materiais.

## 🛠️ Conhecimentos desenvolvidos

Ao longo do curso, o repositório poderá reunir conteúdos relacionados a:

* Lógica e fundamentos de programação
* Python
* HTML, CSS e JavaScript
* Desenvolvimento Web
* Banco de dados
* Arquitetura e organização de computadores
* Desenvolvimento de sistemas
* Controle de versão com Git e GitHub
* Outras tecnologias e ferramentas abordadas durante a formação

## 🎯 Objetivo

Manter um ambiente organizado para acompanhar minha evolução acadêmica, registrar os conhecimentos adquiridos e reunir os materiais, exercícios, atividades e projetos desenvolvidos durante o curso.
